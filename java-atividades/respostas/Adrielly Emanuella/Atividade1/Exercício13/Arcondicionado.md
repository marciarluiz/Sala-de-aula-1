# Exercício 13 — Ar-condicionado

## Objetivo
Criar uma classe para representar um aparelho de ar-condicionado.

## Atributos
- `marca`: marca do aparelho.
- `temperatura`: temperatura configurada.
- `ligado`: informa se o aparelho está ligado.

## Métodos
- `ligar()`: liga o aparelho.
- `desligar()`: desliga o aparelho.
- `aumentarTemperatura()`: aumenta a temperatura até 30 °C.
- `diminuirTemperatura()`: diminui a temperatura até 16 °C.
- `mostrarInformacoes()`: apresenta as informações do aparelho.

## Execução
O programa cria um ar-condicionado, altera seu estado e ajusta a temperatura, respeitando os limites definidos.
