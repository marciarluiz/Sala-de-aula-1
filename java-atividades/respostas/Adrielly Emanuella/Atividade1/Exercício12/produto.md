# Exercício 12 — Controle de Estoque

## Objetivo
Criar uma classe para controlar a quantidade de produtos disponíveis em estoque.

## Atributos
- `nome`: nome do produto.
- `preco`: preço do produto.
- `quantidade`: unidades disponíveis em estoque.

## Métodos
- `adicionarEstoque()`: adiciona unidades ao estoque.
- `retirarEstoque()`: retira unidades, sem permitir uma retirada inválida.
- `mostrarEstoque()`: apresenta os dados do produto e a quantidade disponível.

## Execução
O programa cria dois produtos, realiza alterações no estoque e exibe as quantidades finais.
