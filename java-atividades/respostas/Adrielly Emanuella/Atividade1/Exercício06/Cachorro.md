# Exercício 6 — Cachorro

## Objetivo
Criar uma classe que represente um cachorro e suas características.

## Atributos
- `nome`: nome do cachorro.
- `raca`: raça do cachorro.
- `idade`: idade do cachorro.

## Métodos
- `latir()`: simula o latido do cachorro.
- `brincar()`: mostra uma mensagem de brincadeira.
- `exibirDados()`: apresenta os dados do cachorro.

## Execução
O programa cria três cachorros e exibe seus dados e comportamentos.
