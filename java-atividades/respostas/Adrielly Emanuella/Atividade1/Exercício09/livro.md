# Exercício 9 — Livro

## Objetivo
Criar uma classe para representar livros e controlar se estão abertos ou fechados.

## Atributos
- `titulo`: título do livro.
- `autor`: nome do autor.
- `numeroPaginas`: quantidade de páginas.
- `aberto`: indica se o livro está aberto.

## Métodos
- `abrirLivro()`: abre o livro.
- `fecharLivro()`: fecha o livro.
- `mostrarDetalhes()`: apresenta os dados do livro.

## Execução
O programa cria três livros e demonstra operações de abertura, fechamento e exibição de detalhes.
