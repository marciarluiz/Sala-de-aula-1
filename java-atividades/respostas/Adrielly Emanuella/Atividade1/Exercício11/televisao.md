# Exercício 10 — Calculadora

## Objetivo
Desenvolver uma calculadora com as quatro operações matemáticas básicas.

## Métodos
- `somar()`: realiza uma soma.
- `subtrair()`: realiza uma subtração.
- `multiplicar()`: realiza uma multiplicação.
- `dividir()`: realiza uma divisão e verifica se o divisor é zero.

## Execução
O programa demonstra as operações utilizando números de exemplo e verifica a tentativa de divisão por zero.
